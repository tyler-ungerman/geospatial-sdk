# Security

Please report suspected vulnerabilities privately to the repository maintainer,
using GitHub's private vulnerability reporting if it is available for this
repository. Do not include credentials, private datasets or exploit details in
a public issue. If private reporting is unavailable, contact the maintainer
privately before sharing sensitive details.

Local extract manifests are trusted source claims. Checksums detect changes to
the data relative to a manifest; they do not authenticate its author or its
coverage assertions. Treat external snapshots as untrusted input and verify
publisher identity separately.
